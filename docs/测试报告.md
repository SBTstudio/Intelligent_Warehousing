### 2.2 关键用例

- `test_finds_injected_affinities_in_sample_data`：
  示例数据里埋了 7 组连带关系（啤酒→花生米、可乐→薯片等），
  算法实际挖出 14 条规则（每组双向各一条），前 3 组全部命中。
- `test_dirty_file_contains_invalid_rows` +
  `test_validate_dirty_file_reports_line_numbers`：
  脏数据文件 6 行中 4 行非法，全部被拒绝，错误信息带行号。
- `test_reimport_is_idempotent`：同一订单导入 3 次，明细仍只有 1 条。
- `test_original_file_is_not_modified`：校验前后文件 SHA-256 一致。
- `test_generate_report_falls_back`：模型不可用时返回模板报告且 `used=False`。
- `test_extract_json_handles_code_fence`：```` ```json ```` 包裹可正确解析。
- `test_remote_chat_uses_openai_protocol`：第三方 API 走
  `/chat/completions`，带 Bearer Key 和正确 payload。
- `test_remote_json_falls_back_without_response_format`：服务商不认
  `response_format` 时自动去掉并重试。
- `test_remote_auth_failure_is_reported`：401 能分类提示鉴权失败。

## 三、性能与容量实测

执行命令：

```bash
python tools/benchmark_scale.py
```

测试参数：1095 天 × 300 SKU × 日均 100 张小票。

### 3.1 容量

| 项目 | 结果 |
|---|---:|
| 小票数 | 124,476 |
| 销售明细 | 319,494 |
| 库存快照 | 328,500 |
| 合计 | **772,470 行** |
| 数据库文件 | **59.7 MB** |
| 批量导入耗时 | 5.6 秒 |

需求要求至少 2 年、总量 <2 GB；三年数据仅 59.7 MB，余量充分。

### 3.2 查询性能

| 场景 | 耗时 | 需求上限 | 结论 |
|---|---:|---:|---|
| 购物篮明细（近 90 天） | 15 ms | 3 s（小规模） | ✅ |
| 单 SKU 日销量（近 90 天） | 4 ms | 3 s | ✅ |
| ABC 销售额汇总（近 365 天） | 74 ms | 15 s | ✅ |
| 全周期库存快照聚合 | 17 ms | 15 s | ✅ |
| 全量销售明细（无窗口，31.9 万行） | 248 ms | 15 s | ✅ |

### 3.3 分析算法耗时（示例数据）

| 操作 | 耗时 |
|---|---:|
| 购物篮分析（1,579 张篮，14 条规则） | <0.05 s |
| 补货 + 分类（30 SKU，4,295 明细） | 0.05~0.07 s |
| 报告生成（模型缺失，模板兜底） | <1 s |
| 报告生成（模型可用，4B） | 约 5~20 s（随硬件） |

### 4.1 降级验证

测试时本机只安装了 `bge-m3`（嵌入模型），没有 `qwen3:4b`。
期望行为：

1. 状态栏显示"模型：不可用 · 统计模式"；
2. 报告页顶部显示琥珀色横幅；
3. 报告正文以"【基础统计模式】"开头，包含完整统计结论；
4. 补货、分类、图表正常。

实际结果与期望一致，见 `screenshots/06-report.png`。

### 4.2 异常路径

| 场景 | 实际行为 |
|---|---|
| 导入 `receipts_dirty.csv` | 拒绝，列出 4 条带行号错误 |
| 导入只有表头的文件 | 提示"没有数据行" |
| 编码非 UTF-8/GBK | 提示尝试过的编码 |
| 数据库为空点分析 | 提示先导入示例数据 |
| Ollama 端口关闭 | 立即降级，无卡死 |
| 第三方 API Key 错误 | 提示 401/403，模板兜底 |
| 第三方 API 不支持 response_format | 自动去掉后重试 |
| 卖出库存不足 | 拒绝操作，不产生销售流水 |
| 实时卖出/补货 | 更新库存并写入 inventory_events |
| 模型返回非 JSON | 重试 1 次后降级（单测覆盖） |

## 五、缺陷与限制

| 编号 | 描述 | 影响 | 处理 |
|---|---|---|---|
| L-01 | 示例数据日销量波动大，XYZ 多为 Z | 分类展示偏单一 | 文档说明；后续支持按周聚合 |
| L-02 | 未实现 M14 客户画像 | 需求 1.1 目标 2 未覆盖 | 写入后续迭代，需要真实会员数据 |

| L-04 | 未打包 exe / dmg | 非技术用户安装门槛 | 后续 PyInstaller |
| L-05 | PowerShell/终端中文路径 | 个别环境可能显示异常 | 已在 macOS 中文路径下验证通过 |

> 以上限制均不影响核心验收项；L-01~L-03 已在 README 的 Roadmap 中列明。

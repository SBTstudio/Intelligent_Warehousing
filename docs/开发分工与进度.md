### 三个高频问题

**Q1：Apriori 是自己写的吗？**
打开 `app/core/basket.py`，讲 `_candidate_pairs()` 的剪枝和
`find_frequent_itemsets()` 的逐层计数。明确说明没有用 `mlxtend`，
因为需要自己控制支持度口径、lift 输出格式和性能。

**Q2：为什么不用云端大模型？**
需求 2.2.3 明确要求端侧、保护商业机密；本地 4B 模型在结构化任务上
配合 `format=json` 已经能在数秒内返回合法 JSON，成本为零。

**Q3：本地模型算错数怎么办？**
数字全部由 `app/core/` 产出，LLM 只接收聚合摘要写文字。
`chat_json()` 做 JSON 校验 + 重试 + 降级三层防护；模型不可用时
报告页显示"基础统计模式"，库存和补货功能不受影响。
